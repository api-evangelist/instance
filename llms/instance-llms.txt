# Instance (Instance Labs)

> Verification layer for robot learning. Instance ingests raw robot rollouts and episode footage from any robot or camera angle and automatically judges whether a task was completed successfully, returning a verdict with supporting evidence and a detailed subtask breakdown. Y Combinator-backed (Summer 2026). Generated by the API Evangelist enrichment pipeline from the public demo backend's OpenAPI; there is no provider-published llms.txt.

## APIs

- [Robot Rollout Verifier API](https://demo.instancelabs.ai): Hosted verification API (FastAPI, OpenAPI 3.1). Submit a rollout video + task instruction, get a success/failure verdict.

## Specs

- [OpenAPI (verifier)](https://raw.githubusercontent.com/api-evangelist/instance/refs/heads/main/openapi/instance-verifier-openapi.json): OpenAPI 3.1 for the demo verifier backend.
- [OpenAPI Overlay](https://raw.githubusercontent.com/api-evangelist/instance/refs/heads/main/overlays/instance-verifier-overlay.yaml): API Evangelist enhancements (servers, tags).

## Key Operations

- POST /v1/verify — verify ONE robot-rollout video against a task instruction; returns success/failure/null.
- POST /v1/batch — start a multi-attempt / multi-video verification batch (returns batch_id).
- GET /v1/batch/{batch_id} — poll batch status and results.
- POST /v1/verify_frames — verify pre-sampled frames (with optional timestamps).
- GET /api/job/{job_id} — poll an async upload-based verification job.
- GET /api/usage — retrieve API usage.
